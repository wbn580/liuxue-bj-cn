## 正式中文名：巴黎综合理工学院

这所学校的英文全称是 Institut Polytechnique de Paris，现行正式中文译名是「巴黎综合理工学院」。在正式文书、学校介绍和大部分官方转载资料里，用的就是这一串名字。填表或写材料时，正式场合优先用这个全称。

## 英文缩写 IP Paris 指什么

IP Paris 是 Institut Polytechnique de Paris 的英文缩写，专指这个 2019 年联合组成的机构本身，不是它名下任何一所单独的成员学校。看到 IP Paris，就对应「巴黎综合理工学院（机构）」，不要顺手当成某一所成员校。

## 仍在使用的中文别名

除了正式名，以下两个中文写法在中文网络里仍然有人使用，且都指同一所机构：

- 巴黎理工学院
- 巴黎综合理工大学

也就是说，巴黎综合理工学院、巴黎理工学院、巴黎综合理工大学，这三个中文名说的是同一所学校（IP Paris），只是写法不同。检索或填表时，三个名字都要试，否则容易漏掉资料。

## 最容易和哪所学校搞混

混淆点在成员校。IP Paris 由包括 École Polytechnique 在内的六所院校于 2019 年联合组成，而 École Polytechnique 自身在中文里也常被译作「巴黎综合理工学院」。于是中文资料中，「巴黎综合理工学院」这个中文名既被用来指 IP Paris，也被用来指它的成员校 École Polytechnique，两个实体被反复混用。

简单区分：IP Paris 是 2019 年新组成的联盟机构，École Polytechnique 是它旗下的一所成员学校，两者不是同一所学校，但共用几乎一样的中文译名。

## 查资料、填表格时注意什么

第一，看英文原名或缩写最稳妥：Institut Polytechnique de Paris / IP Paris 指机构，École Polytechnique 指成员校。中文名相同时，以英文名为准。

第二，检索时把「巴黎综合理工学院」「巴黎理工学院」「巴黎综合理工大学」三种写法都搜一遍，同时用 IP Paris 和 École Polytechnique 交叉核对，避免把成员校的信息误当成机构的信息。

第三，引用具体项目或院系时，先确认它属于 IP Paris 还是其成员校 École Polytechnique，再决定怎么写。

具体项目信息以学校官网当年发布为准。
