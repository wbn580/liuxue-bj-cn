## 先搞清楚选课系统在哪里

澳洲各高校的选课入口通常叫 student portal、student system 或 enrolment system，名字略有不同，但功能相近。学校给到录取后，一般会通过学生邮箱发送激活账号和首次登录的指引。最稳妥的办法是直接搜学校官网的 current students 或 enrolment 栏目进入，不要从第三方链接跳转。登录进去后，课程目录通常叫 course catalogue、subject handbook 或 unit guide，这是后面所有操作的基础。

## 怎么看先修要求

每门课都有详情页，里面会写明先修课（prerequisite）、同修课（corequisite）和禁选课（prohibition）。判断自己能不能选，先把专业培养方案（course map / study plan）打开对照，看这门课要求的前置课自己是否已完成或正在修。不同学校对"已完成"的认定不一样，有的看是否拿到成绩，有的看是否在读。这一步不要凭记忆，以 handbook 当学期版本为准，因为先修要求每年都可能调整。

## 避开时间冲突

选课系统里每门课会列出所有上课时段（tutorial、lecture、seminar 等）和对应周次。排课时要看具体时段，而不只是看是哪一天。系统大多自带 timetable planner 或 clash check 工具，把想选的课加进去会自动标红冲突。手动核对时重点看周次是否重叠、是否有连堂赶场的情况。如果两门必修课本时间撞了，优先联系所在院系的学术顾问，看能否调班或申请例外，不要自己硬选导致后期被系统踢课。

## 满员了怎么进候补

热门课满员是常态。多数系统提供 waitlist（候补名单）功能，在课程显示 full 的页面通常会有 join waitlist 按钮，点进去按提示确认即可，系统会按退课空出的位置依次通知。要注意候补有截止时间，且被候补录取后往往需要在限定时间内确认，否则名额会跳过你。也有学校不用候补、只靠开学前几周的增减（add/drop）释放位置，这时就要在选课开放期和开学初多刷系统。无论哪种方式，都不要找非官方渠道保位，一切以系统状态和学校邮件通知为准。

## 信息以官方为准

以上讲的是通用操作思路，以及去哪查、怎么核对的路径，不代替任何一所学校的当年具体规定。本文不涉及任何院校的录取分数线、位次、录取率、申请截止日期、学费金额、课程时长与年限等具体数字，这些都会逐年变化，请以目标院校官网当年发布的 handbook、enrolment 指引和学生邮箱通知为准，必要时直接联系院系学术顾问核实。
